# Character continuity — MCS only

MCS is Make Character Sheet. This contract applies to people/characters, including wardrobe edits; it does not load the vehicle camera plan or VIN protocol.

Use the current explicit MCS command, regardless of a previous vehicle task, active project asset, VIN, name or source arrangement. MCSRLSMPL and MCSCBSMPL require exactly six equal full-height columns in one row, final 16:9: front full body, exact 90-degree profile full body, three-quarter full body, rear full body, front face portrait, exact 90-degree profile face portrait. Four complete bodies and two complete heads/shoulders, neutral gray studio, consistent scale, no cropped extremities, no extra body rotations or stacked panels. Keep the exact supplied character name on the final sheet. Do not print the project label unless requested. Complex MCS keeps its existing six core views plus approved source-evidenced details. RL is photographic live-action; CB is comic/concept.

Inspect and pass actual original reference images to the host renderer. Freeze face, age, complexion, body proportions, anatomy, hair and original clothing unless the user specifically authorizes an attribute change. Do not add weight or reinterpret identity. Ordinary non-explicit swimwear retains its source outfit and coverage under the existing safety rules. An edit changes only the requested appearance attributes; it never selects more panels or the vehicle layout.

Direct chat uploads can render without creating project records. For saved characters, resolve the exact project and character first, then use manage_asset_identity edit/resolve_edit on that character and prepare_sheet with its current mode/medium. Retrieve actual image bytes with get_asset_identity include_media=true. Render through the host, save real output bytes through existing upload tools, and record_sheet with inspection notes, face_identity/anatomy/wardrobe/format checks and an observed sheet_layout. The layout must describe the actual rendered type, medium, mode, core_views, total_panels and rows. For simple MCS, reject any result other than four bodies plus two faces in one row. Only explicit approval of that exact reviewed image authorizes approve_sheet. Existing legacy records retain prepare_wardrobe_edit and generation permits, with the same observed layout validation.

Base identity, approved changes and active visual reference stay separate. Preserve previous edits and exact original references; save recoverable history. An approved corrected sheet becomes the active reference without replacing the original identity. Do not treat the rejected extra-panel sheet as an approved source.

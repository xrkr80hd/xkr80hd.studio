# IGNITION — Studio Asset Department and Director Queue

## XCE CORE RULES v2.3 apply
The XCE CORE RULES v2.3 at the top of SKILL.md govern this file. Where this file disagrees with them (XSTUDIO anchor access, one frame per image, frame counts, numbering, naming, the per-frame review gate, invideo video, native audio only), the core rules win.


Input: DIRECTOR build queue with source inputs, source kind, required views, member-role roster, continuity, linked shots, exact output type and quality acceptance. Output: actual image results or blocked/failed status with receipt and visual review. No artificial approval gate during UNIFY-authorized batch. When standalone direct MCS/MVS request, use this contract's existing formats without requiring Director.

REUSE means no new generation: bind exact user-available image; list source and any limited views. NEW generates from a reproducible original fictional description; characters remain consistent within each image but generative tools can drift. MIXED reuses existing identity as mandatory input to create missing angles or new wardrobe variants. A group photo source may need additional angle coverage only when the shot requires it. Do not generate individual turnarounds for all members of a recurring crew by default; director selects heroes. Record exact identities linked to group member IDs. Characters in fantasy environments must be the same cast as the reality version. Group anchors count as one group asset, not a verified complete set of individual anchors.

Six-slot simple character sheet (built per core rule 3 from six single renders, assembled with Python): one horizontal row of 6 columns on 16:9, front body; strict left-facing full body; 3/4 body; rear body; enlarged frontal head; enlarged strict left-facing profile head. Vehicles: nine-view coverage including 2 interiors when sources support accuracy. Props: practical consistent angles, markings, scale, grip/contact. Locations: entry points, route, counters, fixed geometry; concept distinction from real. User's supplied source beats any fictional substitute. Actual tool output returns source locator/attachment; only mark REVIEWED on actual inspection.

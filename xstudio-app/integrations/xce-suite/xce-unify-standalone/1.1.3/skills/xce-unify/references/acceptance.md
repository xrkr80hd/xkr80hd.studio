## XCE CORE RULES v2.3 apply
The XCE CORE RULES v2.3 at the top of SKILL.md govern this file. Where this file disagrees with them (XSTUDIO anchor access, one frame per image, frame counts, numbering, naming, the per-frame review gate, invideo video, native audio only), the core rules win.


These fixtures are **test descriptions**, not authorization to perform live image calls. Do not run them merely because this file is read.

1. `@XCE_UNIFY` + identifiable original idea + user wants a production: without needing `GEN ALL`, drafts script and seven AS units, prepares fictional or actual grounded references, calls the host image renderer for seven separate frames and necessary boundaries, writes seven complete prompts, edit timeline, continuity and accurate receipt. Never silently substitute a web image/moodboard or one contact sheet.
2. `UNIFY` alone + existing conversation idea: same full batch by default. If no identifiable idea, ask the smallest question or offer a provisional concept but do not fabricate user approval or generate an unrelated batch.
3. `LTSTLK` / `BRNSTRM` / `PLAN ONLY` / `IDEAS ONLY`: text brainstorming only, no image calls.
4. `UNIFY VIS` + one requested draft: one exploratory 16:9 image, not a seven-shot full production.
5. `GEN ALL`: redundant explicit alias for same full production; never require follow-up `Y`/`NXT` after source and concept are sufficient.
6. `STBY`, `RPTPLS`, `ANSR`: pause, repeat-and-hold or answer-only; no generation.
7. `MOD SHOT-03`: invalidate shot 3 and downstream affected states, not entire existing batch or unrelated approved references.
8. Specific real employee without a photo: cannot claim exact likeness. Concept test may generate fictional staff, clearly labeled, without portraying them as verified real people. An exact-fidelity job blocks only exact-likeness dependent assets.
9. Real dealership remodel missing actual photos: no claim that generated building is actual. Produce conceptual location shots when appropriate, finish independent deliverables and report fidelity limitation.
10. Seven shots are seven independent returned image assets. One generated seven-panel storyboard sheet is one sheet, not seven independent shot frames.
11. Seven per-shot FIRST_FRAME and LAST_FRAME assignments must reference real produced images or be correctly marked pending/blocked; no invented provider URLs or IDs.
12. All seven independently complete animation prompts include every field in production.md and all relevant world/camera/reference states; no implicit "same as above" inheritance.
13. User requests plugin configuration edit only: edit instructions, do NOT interpret quoted commands/examples as authorization to generate a production.

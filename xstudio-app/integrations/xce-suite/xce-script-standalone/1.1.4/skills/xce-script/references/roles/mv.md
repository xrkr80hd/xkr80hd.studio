# XCE_MV v2.0 — Director Signature Engine

## XCE CORE RULES v2.4 apply
The XCE CORE RULES v2.4 at the top of SKILL.md govern this file. Where this file disagrees with them (XSTUDIO anchor access, one frame per image, frame counts, numbering, naming, the per-frame review gate, invideo video, native audio only), the core rules win.


Read and apply [DSE](../dse.md) for director selection, preset translation, per-shot checks and the explicitly requested storyboard-sheet delivery mode. DSE's SHEET rules apply only when the user types SHEET after every frame is APPROVED; ordinary MV remains seven separate 16:9 frames. DSE adds a cinematic language layer; it preserves this role's SS/AS semantics, shot counts, approval flow, reference handling and separate full-bleed 16:9 delivery.
Director mode from supplied images and scene direction. Keep source identity, proportions, wardrobe, props, geography, world-space light, screen direction and eyelines. Preserve original anchors alongside the establishing frame. Actual images must reach the host renderer; seed/prompt/schema checks do not guarantee likeness.

SL starts Shot List planning. Ask SS (Same Shot) or AS (Advancing Shot) once unless supplied. SS freezes one instant across views; AS advances narrative, each shot starting from the preceding ending. In this role SS never means Start Story. CESRL+MV/CESCB+MV select realistic/comic and Same Shot; +MVAS selects advancing mode. Shortcuts/uploads alone do not render. FF = Final Frame, shot 7; LF remains an alias. The chosen ending overrides the default insert, never adds an eighth shot.

Standalone seven-shot route: recommend one shot at a time, include DSE's brief camera, lens, settings or lighting tip for the current choice, and wait for confirmation. Default recommendations: (1) establishing extreme wide, (2) alternate wide, (3) vertical-axis angle, (4) subject B close-up, (5) reverse close-up of the SAME B, (6) wide profile, (7) detail insert or user-selected FF. Do not invent a second person to fill B. Explicitly confirm FF, recap the full list, then ask exactly: Generate these now? Y / GEN / N / MOD. Y/GEN here renders the reviewed batch; Y during shot planning confirms that shot only. N preserves list and stands by. MOD revises named shots, reconciles continuity, repeats the entire revised list and the same final question. Earlier approvals do not authorize a changed list.

After final authorization, render all seven separate full-bleed 16:9 images in order without additional NXT gates between them. One image per call; no grid/contact sheet, bars, borders, text or watermark. Use realistic RL or consistent comic CB. Default cinematic look is cool restrained tones, organic blacks, natural colors, subtle grain, anamorphic depth without letterboxing; a user-selected grade overrides that default. Preserve world-light positions under reverse cameras. Do not spend paid credits. Report actual completed count and failures honestly. Do not replace original anchors with the newest output or treat generation as final approval.


Per-shot assignment uses actual supplied images and names, with independent cast mapping per shot. Fetch anchors from XSTUDIO through the XCE app by exact code when connected (core rule 1); otherwise use images in this chat. Keep shot titles, ordinal, prompt, cast/reference map, SS/AS mode, action, dialogue, camera, duration, review decision and output receipt in conversation. Name/export a shot list only when requested. If packaging is requested and real files exist, include individual images and prompts; otherwise report unavailable bytes rather than inventing a ZIP. External generator names are manual prompt targets, not connected services.

## CGE — in-chat grade module
On standalone cge reply exactly: Supply a pic or name a style. Preserve the pending shot workflow; no generation on that trigger. An image path analyzes actual visible shadows/midtones/highlights, contrast, temperature/tint, saturation, grain and halation, distinguishing estimates from measurements. A raw grading prompt is parsed without an unsolicited image. Output canonical grade JSON with grade_id, name, status:STAGED, prompt_token_string and parameters, plus reusable grading prompt. Do not infer original Kelvin, stock or exact numeric controls from pixels.

A named-style request authorizes exactly ONE standalone 16:9 confirmation image, followed by a concise explanation and: Confirm this grade to lock and parse, or describe adjustments. Adjustments revise that one example; confirmation locks the look in-session and outputs JSON/prompt, still STAGED. Preserve identity, clothing colors and world lights. No upload/sync/API/save endpoint. For edits, use user-supplied preset data, keep originals and change requested fields only. Do not claim a .cube LUT or calibrated transform exists. Carry the selected look unchanged between shots until explicitly revised.

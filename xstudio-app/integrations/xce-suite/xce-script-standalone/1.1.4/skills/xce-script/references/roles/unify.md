# XCE_UNIFY v1.0.1 — operational contract (complete production default)

## XCE CORE RULES v2.4 apply
The XCE CORE RULES v2.4 at the top of SKILL.md govern this file. Where this file disagrees with them (XSTUDIO anchor access, one frame per image, frame counts, numbering, naming, the per-frame review gate, invideo video, native audio only), the core rules win.


## Modes and creative authority
Default mode for `@XCE_UNIFY`, `XCE_UNIFY` or `UNIFY` with an identifiable idea is AUTO_PRODUCTION. Immediately initiate full `GEN ALL` without separate user authorization or intermediate confirmations. Full generation encompasses script, seven AS units, anchors as available, seven separately rendered full-bleed 16:9 cinematic keyframes, appropriate boundary images, complete animation handoffs, edit timeline and honest status report. Never stop at text-only concept, web moodboard or one collage in this default mode. `GEN ALL` remains an explicit alias for the same behavior, not a mandatory second trigger.

CREATIVE_PLAYGROUND remains explicitly available under `LTSTLK`, `BRNSTRM`, `IDEAS ONLY` or `PLAN ONLY`, with no rendering. `UNIFY VIS` makes the explicitly requested count/type of exploratory images (one 16:9 if no count); these do not silently become approved canon. `ANSR`, `RPTPLS`, `STBY`, `SHFT` retain their hold/answer-only behavior. A request to change plugin logic is a configuration task and does not itself execute cinematic generation. Preserve human decisions, selected concepts, source facts and rejected ideas; use labeled defaults only for unstated nonessential matters.

## Input/source handling
Use current conversation context and accessible user references. A YouTube link mentioned as inspiration is not a mandatory retrieval request; don't claim to have watched inaccessible visuals. If user explicitly requests source analysis, verify what can be accessed. Neither missing YouTube visuals nor missing photos automatically block an ORIGINAL concept test. When an exact employee likeness, real floor plan, actual inventory or identifiable site is essential, require real references for those exact-fidelity assets; meanwhile generate all independent, conceptual/fictional portions under clearly labeled concept mode. User-defined action, composition and camera routes override defaults.

## Full execution sequence
1. Snapshot selected concept, script length (default 30 seconds for short commercial if unspecified), user constraints, location intent, director, color grade, count and source availability. Mark assumptions as PROPOSED.
2. FIRESTARTER: state protagonist, goal, audience, visual hook, conflict, world-transformation logic and payoff. Never rewrite a user-selected premise.
3. SCRIBE: write a timed, causal 7-beat script, separating voice, dialogue, native ambience and SFX (never music). Sum exact beat durations to runtime, make speakable lines and avoid invented incentives.
4. MV: produce precisely seven ADVANCING shots by default, each with start world state, end state, camera/lens/light intent, time range, continuity and cut behavior. Director Signature Engine controls actual shot style, not only a label.
5. Build references before image rendering: CH-01 onward for each recurring visible fictional person, LC for each real or imagined location, VEH when actually present, PR for props. Never add extras solely to fill a preset. A real person requires their actual source photo for any claimed likeness.
6. IGNITION: generate needed and supported six-view character turnaround anchors from supplied real images or clearly approved/conceptual fictional designs. Preserve identity, wardrobe, anatomy, prop and orientation in all views. Default six-slot MCSRLSMPL contract: one uninterrupted horizontal row, four full bodies (front, strict left side, three-quarter, rear) then enlarged front and left-profile faces. Never silently claim a set of mood photos is an actual anchor. Use the host's image tool in the SAME chat. If specific real subject/source is unavailable, generate only a fictional concept or mark exact-likeness asset BLOCKED while proceeding independently.
7. Generate SEVEN separate full-bleed 16:9 frames (or the user's explicit count), one unique shot per rendered image, one image call each; maintain same characters and real/imaginary world rules. Never substitute a single contact sheet, image search results, or cropped panels. When the host returns inaccessible/failed image, mark that shot pending/failed, proceed with supported independent scope and report exact count.
8. For each AS unit record FIRST_FRAME and LAST_FRAME with suitable actual image assignments; reuse existing frame only when composition and state genuinely match, otherwise generate required independent boundary images when tools allow. Do not equate narrative final shot `FF` with the LAST_FRAME of every shot. Boundaries are not extra narrative shots.
9. Write one completely self-contained video animation prompt per frame (each ending "Native audio only. No music."), with all fields in production.md, including start/end image references or clearly labeled unfilled slots, camera/subject timed motion, lighting, negative constraints, audio and transition. Optional provider-adapted handoffs only if requested/selected; don't invent a generator's controls or submit external render jobs automatically.
10. Finish an edit timeline, per-shot continuity assessment and the full twelve-part report; counts distinguish images generated, inspected, reused, blocked, failed, planned. No phantom URLs/files/provider IDs, no approval claims before user review. Continue without gate until authorized scope is completed or tool limit stops it.

## Anchors
Character refs: CH-01 onward; independent six-slot sheets per recurring character by default. Keep original face/skin/hair/wardrobe across full-body and portrait views. Actual photos outrank fictional text. Any unprovided specific real identity remains unknown; concept stand-ins must be labeled fictional and never presented as a reconstruction of that person.

Vehicle refs: VEH-01 onward; nine-view package when a hero vehicle exists: front, front driver three-quarter, driver profile, rear, passenger rear three-quarter, passenger profile, overhead, front cabin, rear cabin. Preserve supplied make/model/year/trim and verified design. No VIN inference, invented trim details or unsupported seats/interiors.

Location refs: LC-01 onward; use actual source images to reproduce recognizable real architecture and signs. Conceptual stand-ins are appropriate when exact site depiction is not required. Maintain physically coherent routes, shelves/counters, light sources and the relationship between real location and imaginary stadium.

## Cinematography and continuity
Default clean premium naturalistic commercial style; KOSINSKI when explicitly selected inherits precision tracking, clean wides, disciplined blocking, premium but credible movement and natural practical-light integration. Director signature and color grade remain separate. AS advances action, SS freezes one instant; a new camera cut does not teleport a character or prop. Maintain travel direction, screen position, hand ownership, battery/football transformation at match cuts, actor relationships, costume changes limited to dream-state and no accidental changes to established floor geometry.

Images are separate 16:9 landscape outputs, no borders, sheets, titles, watermarks, text overlays or black bars; a requested STORYBOARD SHEET/BOTH adds a supplemental composition but does not replace seven standalone frames. Preserve original references and inspect actual returned images. Limit corrections to two per affected frame without new user direction, keep prior receipts.

## Audio, video and editing
Motion prompts must describe beginning/ending states, moving and stationary subjects, timing, proposed camera/lens movement, motivated light and grade, environment movement, transitions, negative constraints, source images when actually available, dialogue/VO/native SFX and ambience; never music. Do not say "same settings as last" or claim external paid jobs were run. Never add music; cut rhythm comes from action and native sound. Keep external footage rights unresolved, use original audio for production unless licensed.

Track production.md's single manifest in this chat with truthful statuses PLANNED, GENERATED, REVIEWED, APPROVED, BLOCKED, FAILED. GEN ALL authorization is not a substitute for visual user approval. Optional compact status: stage, completed images, missing references and next pending output. Report all twelve sections: 01 Concept; 02 Script; 03 Character anchors; 04 Vehicle anchors; 05 Location refs; 06 Seven AS shots; 07 Seven separate cinematic frames; 08 First/last assignments; 09 Seven independent complete prompts; 10 Edit timeline; 11 Continuity; 12 Actual delivery report. When rendering temporarily fails or exceeds tool limits, continue the other work, preserve what exists and state exactly what is left. No background process or external persistence implied.

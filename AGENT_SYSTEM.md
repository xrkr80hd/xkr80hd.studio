# Agent System

This workspace uses the LICL loop for repository work:

1. Log the intended work in `planned_work.md`.
2. Implement only the confirmed scope.
3. Check the resulting diff and run relevant verification.
4. Log finished work in `completed_work.md`.

Mixed worktrees must be staged explicitly. Unfinished features remain local unless the user asks to publish them.

## Trav's control preference
Use switches for settings that turn a behavior on or off in all builds. Keep checkboxes for selecting items or explicit confirmations. Asset viewers always show left/right image-edge arrows; automatic advance is always on, with no Auto-Next control. The owner closes the viewer when finished.
